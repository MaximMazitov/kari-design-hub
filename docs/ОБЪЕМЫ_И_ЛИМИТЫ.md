## 💾 Хранилища Данных

### 1. LocalStorage (Браузер)

**Тип:** Синхронное Key-Value хранилище
**Лимит:** 5-10 MB (зависит от браузера)
**Скорость:** Очень быстрая (в памяти браузера)
**Персистентность:** Постоянная (пока не очистят данные)

#### Используемые ключи:
```javascript
'kari-capsules'      // Все капсульные коллекции
'kari-items'         // Все артикулы (SKU)
'kari-palettes'      // Цветовые палитры
'kari-prompts'       // Шаблоны промптов
'kari-checklists'    // Чеклисты качества
'kari-theme'         // Тема (light/dark)
'kari-guest-mode'    // Режим работы (true/false)
```

#### Размеры данных:

| Объект | Средний размер | Пример |
|--------|---------------|--------|
| 1 капсула (мета) | ~2 KB | Название, сезон, статусы |
| 1 артикул | ~1.5 KB | SKU, название, промпт (300 символов) |
| 1 артикул (полный) | ~2.5 KB | С длинным промптом Midjourney (800 символов) |
| 1 палитра | ~1 KB | 6 цветов Pantone TCX |
| 1 промпт-шаблон | ~0.5 KB | Few-shot пример |

#### Расчёт вместимости:

**Максимальная ёмкость (5 MB):**
```
Капсулы (метаданные):  20 капсул × 2 KB     = 40 KB
Артикулы (500 шт):     500 × 2.5 KB         = 1,250 KB
Палитры (20 шт):       20 × 1 KB            = 20 KB
Промпт-шаблоны (50):   50 × 0.5 KB          = 25 KB
Резерв (чеклисты):                          = 50 KB
                                      ИТОГО = 1,385 KB (~1.4 MB)
```

**Вывод:** LocalStorage может хранить:
- ✅ ~20-50 капсул
- ✅ ~500-2,000 артикулов
- ✅ ~20-50 палитр
- ✅ ~50-100 промпт-шаблонов

**Ограничение:** При достижении лимита браузер выдаст `QuotaExceededError`

### 2. Firebase Firestore (Облачная БД)

**Тип:** NoSQL Document Database
**Провайдер:** Google Cloud Platform
**План:** Spark (бесплатный)

#### Лимиты Free Plan (Spark):

| Ресурс | Лимит | Комментарий |
|--------|-------|-------------|
| **Хранилище** | 1 GB | Общий объём данных |
| **Загрузок (Network)** | 10 GB/день | Исходящий трафик |
| **Операций чтения** | 50,000/день | Get, Query |
| **Операций записи** | 20,000/день | Set, Update, Delete |
| **Удалений** | 20,000/день | Delete operations |
| **Одновременных подключений** | 100 | WebSocket connections |

#### Структура коллекций:

```
/users/{userId}/
    capsules/           (Коллекция капсул)
        {capsuleId}     (Документ капсулы ~2 KB)

    items/              (Коллекция артикулов)
        {itemId}        (Документ артикула ~2.5 KB)

    palettes/           (Коллекция палитр)
        {paletteId}     (Документ палитры ~1 KB)

    settings/           (Настройки пользователя)
        preferences     (~0.5 KB)
```

#### Расчёт объёма для одного пользователя:

**Средний дизайнер (10 капсул):**
```
Капсулы:     10 × 2 KB    = 20 KB
Артикулы:    250 × 2.5 KB = 625 KB
Палитры:     10 × 1 KB    = 10 KB
Настройки:   1 × 0.5 KB   = 0.5 KB
                    ИТОГО = 655.5 KB (~0.64 MB)
```

**Активный дизайнер (50 капсул):**
```
Капсулы:     50 × 2 KB     = 100 KB
Артикулы:    1,250 × 2.5 KB = 3,125 KB (~3 MB)
Палитры:     50 × 1 KB     = 50 KB
                     ИТОГО = 3.175 MB
```

**Вместимость Free Plan (1 GB):**
- ✅ ~300 активных дизайнеров (по 3 MB каждый)
- ✅ ~1,500 средних дизайнеров (по 0.64 MB каждый)
- ✅ ~15,000 капсул (по 50 KB каждая с артикулами)
- ✅ ~400,000 артикулов (по 2.5 KB каждый)

#### Операции чтения/записи (Free Plan):

**Сценарий:** Активный дизайнер работает 8 часов в день

| Действие | Операций | Комментарий |
|----------|----------|-------------|
| Вход в систему | 1 read | Загрузка капсул |
| Открытие капсулы | 1 read + 25 reads | Метаданные + артикулы |
| Редактирование артикула | 1 write | Update документа |
| Создание капсулы (AI) | 1 write + 25 writes | Капсула + артикулы |
| Автосинхронизация (каждые 1 сек) | 1 write (debounce) | Группировка изменений |

**Итого за день (1 дизайнер):**
- Чтений: ~100-200 операций
- Записей: ~50-100 операций

**Лимит Free Plan:**
- ✅ 50,000 чтений/день → ~250-500 дизайнеров
- ✅ 20,000 записей/день → ~200-400 дизайнеров

**Вывод:** Free Plan достаточен для **100-200 активных дизайнеров** одновременно

### 3. Service Worker Cache (PWA)

**Тип:** HTTP Response Cache (CacheStorage API)
**Лимит:** 50-100 MB (зависит от браузера)
**Назначение:** Оффлайн кэширование статических файлов

#### Кэшируемые ресурсы:

| Ресурс | Размер | Кол-во |
|--------|--------|--------|
| index.html | ~43 KB | 1 |
| styles.css | ~77 KB | 1 |
| JavaScript модули | ~280 KB | 13 файлов |
| manifest.json | ~0.5 KB | 1 |
| icons/icon.svg | ~2 KB | 1 |
| **ИТОГО** | **~403 KB** | **17 файлов** |

**Стратегия кэширования:** Cache First + Network Fallback

```javascript
// Сначала проверяем кэш
caches.match(request)
  .then(cached => {
    if (cached) {
      // Возвращаем из кэша (быстро)
      fetchAndCache(request); // Обновляем в фоне
      return cached;
    }
    // Нет в кэше → загружаем из сети
    return fetchAndCache(request);
  })
```

**Время доступа:**
- Из кэша: < 10 ms
- Из сети: 100-500 ms

## 🤖 Claude API Токены

### Ценообразование (Claude Sonnet 4):

| Тип токенов | Стоимость |
|-------------|-----------|
| Input tokens | $3 за 1M токенов |
| Output tokens | $15 за 1M токенов |

### Расход токенов на генерацию капсулы:

**Входные данные (Input):**
```
System Prompt (MEGA PROMPT):    ~2,500 tokens
User Message (описание):        ~500 tokens
Image (фото бестселлера):       ~1,000 tokens
                         ИТОГО: ~4,000 tokens
```

**Выходные данные (Output):**
```
JSON с капсулой:
  - Capsule metadata:           ~200 tokens
  - Palette (6 colors):         ~300 tokens
  - Looks (3 образа):           ~600 tokens
  - Items (25 артикулов):       ~5,000 tokens
    (каждый промпт ~200 токенов)
                         ИТОГО: ~6,100 tokens
```

### Стоимость одной генерации:

```
Input:  4,000 tokens × $3 / 1,000,000  = $0.012
Output: 6,100 tokens × $15 / 1,000,000 = $0.092
                               ИТОГО:   $0.104 (~10 центов)
```

### Месячный бюджет:

**Один дизайнер:**
- Генераций в месяц: ~20 капсул
- Стоимость: 20 × $0.104 = **$2.08**

**Команда (10 дизайнеров):**
- Генераций в месяц: ~200 капсул
- Стоимость: 200 × $0.104 = **$20.80**

**Команда (100 дизайнеров):**
- Генераций в месяц: ~2,000 капсул
- Стоимость: 2,000 × $0.104 = **$208**
