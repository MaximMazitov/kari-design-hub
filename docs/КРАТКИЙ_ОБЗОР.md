# 🎯 KARI Design Hub - Краткий Технический Обзор

## 📱 Что это?

**KARI Design Hub** - Progressive Web Application (PWA) для управления дизайн-пайплайном детской одежды с интегрированным AI-ассистентом на базе Claude.

---

## 🏗️ Архитектура в Двух Словах

```
┌──────────────┐
│   Браузер    │ ← Vanilla JS (10,379 строк кода)
│   (PWA)      │ ← LocalStorage (5-10 MB)
└──────┬───────┘
       │
       ├─► Firebase Firestore (1 GB облачное хранилище)
       │
       └─► Claude API (через Cloudflare Workers прокси)
```

**Тип:** Client-Side SPA + PWA + Serverless
**Фреймворки:** Нет (чистый JavaScript)
**Сервер:** Python HTTP Server (только для разработки)

---

## 💾 Хранилища

### 1. **LocalStorage (Браузер)**
- **Лимит:** 5-10 MB
- **Хранит:** Капсулы, артикулы, палитры, промпты
- **Вместимость:** ~500-2,000 артикулов

### 2. **Firebase Firestore (Облако)**
- **Лимит:** 1 GB (бесплатный план)
- **Операции:** 50K чтений/день, 20K записей/день
- **Вместимость:** ~100-200 активных дизайнеров
- **Функции:** Синхронизация между устройствами, оффлайн кэш

### 3. **Service Worker Cache**
- **Лимит:** 50-100 MB
- **Хранит:** Статические файлы (HTML, CSS, JS)
- **Назначение:** Оффлайн работа приложения

---

## 🤖 AI Компоненты

### Claude API (Anthropic)
- **Модель:** Claude Sonnet 4 (`claude-sonnet-4-20250514`)
- **Прокси:** Cloudflare Workers (скрывает API ключ)
- **Использование:**
  - Анализ фото бестселлеров
  - Генерация цветовых палитр (Pantone TCX)
  - Создание промптов для Midjourney
  - Генерация описаний артикулов

### Стоимость генерации:
- **1 капсула (25 артикулов):** ~$0.10 (10 центов)
- **Токены:** ~4,000 input + ~6,100 output
- **Время:** 10-30 секунд

## 🔄 Процессы

### Синхронизация данных:
```
Изменение → LocalStorage (немедленно)
          → Debounce 1 сек
          → Firebase Firestore (в облако)
```

### Создание капсулы через AI:
```
1. Пользователь загружает фото бестселлера
2. Заполняет данные (сезон, возраст, пол)
3. AI Wizard формирует MEGA PROMPT (~2,500 токенов)
4. Запрос → Cloudflare Worker → Claude API
5. Claude анализирует фото и генерирует:
   - Цветовую палитру (Pantone TCX)
   - 3-10 образов (looks)
   - 10-50 артикулов с промптами
6. Результат → LocalStorage + Firestore
7. UI обновляется (новая капсула отображается)
```
