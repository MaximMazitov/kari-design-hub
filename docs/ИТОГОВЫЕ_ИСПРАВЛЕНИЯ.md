## 🐛 Известные Проблемы

### Проблема: "AI вернул некорректный JSON"

**Симптомы:**
- Генерация завершается с ошибкой
- Красный крестик в AI Wizard
- Сообщение: "Попробуйте еще раз или уменьшите количество артикулов"

**Причины:**
1. Claude API вернул неполный JSON (обрезался на середине)
2. Слишком много артикулов (> 30)
3. Проблемы с сетью или API

**Решение:**
1. **Попробуйте снова** - иногда помогает
2. **Уменьшите количество артикулов:**
   - Вместо 25 → 15
   - Вместо 5 образов → 3
3. **Проверьте консоль** (F12) для деталей:
   ```
   [Mega Prompt] JSON parse failed: Expected ',' or '}' at position XXX
   [Mega Prompt] Context around error: ...
   ```
4. **Упростите запрос:**
   - Уберите изображение (текстовый режим быстрее)
   - Уменьшите описание бестселлера

---

### Проблема: Claude API Timeout

**Симптомы:**
- Генерация зависает > 60 секунд
- Ошибка: "Request timeout"

**Решение:**
1. Проверьте интернет-соединение
2. Проверьте Cloudflare Workers прокси
3. Уменьшите `max_tokens` в запросе (8000 → 4000)

async function generateWithRetry(params, maxRetries = 3) {
    for (let i = 0; i < maxRetries; i++) {
