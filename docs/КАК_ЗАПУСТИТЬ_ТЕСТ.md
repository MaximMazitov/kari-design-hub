## 🚀 Как запустить тест (2 способа)

### Способ 1: Через консоль браузера (РЕКОМЕНДУЕТСЯ)

1. **Откройте http://localhost:8080 в браузере**

2. **Откройте консоль разработчика:**
   - Chrome/Edge: `Cmd + Option + J` (Mac) или `Ctrl + Shift + J` (Windows)
   - Safari: `Cmd + Option + C`

3. **Скопируйте и вставьте этот код в консоль:**

```javascript
(async function(){
try {
  console.clear();
  console.log("===========================================");
  console.log("🧪 ТЕСТ AI WIZARD - МИНИМАЛЬНАЯ ГЕНЕРАЦИЯ");
  console.log("===========================================");
  console.log("Параметры: 2 образа, 5 артикулов");
  console.log("Режим: без изображения (текстовый)");
  console.log("");

  const startTime = Date.now();

  const result = await window.generateCapsuleWithAI({
    bestseller: {
      sku: 'TEST-001',
      name: 'Куртка тестовая',
      description: 'Простое описание для теста',
      colors: 'черный, белый',
      price: 3990,
      cost: 1200,
      sold: 5000,
      imageBase64: null,
      hasImage: false
    },
    collection: {
      name: 'Test Mini',
      season: 'AW26',
      ageGroup: 'kid',
      gender: 'male',
      segment: 'standard'
    },
    requirements: {
      looksCount: 2,
      itemsCount: 5,
      notes: 'Минимальный тест парсинга JSON'
    }
  });

  const duration = ((Date.now() - startTime) / 1000).toFixed(1);

  console.log("");
  console.log("===========================================");
  console.log("📊 РЕЗУЛЬТАТ ТЕСТА");
  console.log("===========================================");
  console.log("Время выполнения:", duration, "секунд");
  console.log("Успех:", result.success ? "✅ ДА" : "❌ НЕТ");
  console.log("");

  if (result.success) {
    console.log("✅✅✅ ТЕСТ ПРОЙДЕН УСПЕШНО! ✅✅✅");
    console.log("");
    console.log("Создано объектов:");
    console.log("  • Артикулов:", result.data?.items?.length || 0);
    console.log("  • Образов:", result.data?.looks?.length || 0);
    console.log("  • Цветов:", result.data?.palette?.colors?.length || 0);
    console.log("");

    if (result.data?.items?.[0]) {
      console.log("Пример артикула #1:");
      console.log("  Название:", result.data.items[0].name);
      console.log("  Категория:", result.data.items[0].category);
      console.log("  Промпт (200 симв):", result.data.items[0].prompt?.substring(0, 200));
    }
  } else {
    console.log("❌❌❌ ТЕСТ ПРОВАЛЕН ❌❌❌");
    console.log("");
    console.error("Сообщение об ошибке:", result.error);

    if (result.technicalError) {
      console.error("Техническая ошибка:", result.technicalError);
    }

    if (result.rawResponse) {
      console.log("");
      console.log("Сырой ответ (первые 1000 символов):");
      console.log(result.rawResponse.substring(0, 1000));
    }
  }

  console.log("");
  console.log("===========================================");

} catch (error) {
  console.log("");
  console.log("❌❌❌ КРИТИЧЕСКАЯ ОШИБКА ❌❌❌");
  console.error("Исключение:", error.message);
  console.error("Stack:", error.stack);
}
})();
```

4. **Нажмите Enter**

5. **Ждите 30-60 секунд** (генерация через Claude API занимает время)

6. **Смотрите результат в консоли**

## ⚠️ Возможные проблемы

### 1. Ошибка "Expected ',' or '}' after property value"
**Причина:** Claude вернул невалидный JSON
**Решение:** Уменьшите количество артикулов до 3-5

### 2. Долгое ожидание (больше 2 минут)
**Причина:** Claude API медленно отвечает
**Решение:** Подождите еще или перезапустите тест

### 3. Ошибка "generateCapsuleWithAI is not defined"
**Причина:** Модули не загрузились
**Решение:** Обновите страницу (`Cmd + R`) и попробуйте снова

### 4. Ошибка "Failed to fetch"
**Причина:** Cloudflare Worker не отвечает
**Решение:** Проверьте интернет соединение
