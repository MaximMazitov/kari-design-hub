## 💾 Система Хранения Данных

### 1. **LocalStorage (Браузер)**

**Назначение:** Локальное хранилище данных
**Лимит:** ~5-10 MB (зависит от браузера)
**Ключи хранения:**
- `kari-capsules` - Капсульные коллекции
- `kari-items` - Артикулы (SKU)
- `kari-palettes` - Цветовые палитры Pantone
- `kari-prompts` - Шаблоны промптов
- `kari-checklists` - Чеклисты
- `kari-theme` - Настройка темы (светлая/тёмная)
- `kari-guest-mode` - Режим работы (гость/облако)

**Структура данных (пример):**
```javascript
{
  id: 'aw26-signal-boys',
  name: 'SIGNAL Urban',
  season: 'AW26',
  ageRange: '8-12',
  gender: 'boys',
  totalItems: 42,
  paletteId: 'aw26-signal',
  createdAt: '2024-12-20T10:00:00Z'
}
```

### 2. **Firebase Firestore (Облако)**

**Провайдер:** Google Firebase
**Тип:** NoSQL Document Database
**Регион:** us-central1 (вероятно)
**Проект:** `kari-design-hub`

**Конфигурация:**
```javascript
projectId: "kari-design-hub"
authDomain: "kari-design-hub.firebaseapp.com"
storageBucket: "kari-design-hub.firebasestorage.app"
```

**Лимиты (Firebase Spark Plan - бесплатный):**
- **Хранилище:** 1 GB
- **Загрузок в день:** 10 GB
- **Операций чтения:** 50,000/день
- **Операций записи:** 20,000/день
- **Одновременных подключений:** 100

**Коллекции в Firestore:**
```
/users/{userId}/
  └── capsules/         - Капсулы пользователя
  └── items/            - Артикулы
  └── palettes/         - Палитры
  └── settings/         - Настройки
```

**Функции:**
- ✅ Синхронизация между устройствами
- ✅ Оффлайн persistence (кэш в браузере)
- ✅ Авторизация через Email/Password
- ✅ Автоматическая синхронизация при изменениях (debounce 1 сек)

### 3. **Service Worker Cache**

**Назначение:** Кэширование статических ресурсов для оффлайн работы
**Лимит:** ~50-100 MB (зависит от браузера)
**Стратегия:** Cache First + Network Fallback

**Кэшируемые файлы:**
- HTML, CSS, JS файлы
- Manifest.json
- Иконки приложения

## 🔄 Процесс Синхронизации

### Режимы работы:

1. **Облачный режим (Cloud Mode)**
   ```
   Изменения → LocalStorage → Debounce (1 сек) → Firestore
   ```
   - Автосинхронизация при изменениях
   - Двустороння синхронизация (pull + push)
   - Индикатор статуса внизу экрана

2. **Гостевой режим (Guest Mode)**
   ```
   Изменения → LocalStorage только
   ```
   - Без облачной синхронизации
   - Данные только на локальном устройстве
   - Быстрая работа, нет зависимости от интернета

### Логика синхронизации:
```javascript
// При изменении данных
saveCapsules(data) {
  localStorage.setItem('kari-capsules', JSON.stringify(data));

  // Debounce для избежания спама
  clearTimeout(syncTimeout);
  syncTimeout = setTimeout(() => {
    syncToCloud(); // → Firebase Firestore
  }, 1000);
}
```

## 🤖 AI Интеграция

### 1. **Claude API (Anthropic)**

**Модель:** Claude Sonnet 4
**Endpoint:** Через Cloudflare Workers прокси
**Использование:**
- Анализ изображений бестселлеров
- Генерация цветовых палитр Pantone TCX
- Создание промптов для Midjourney
- Генерация описаний артикулов

**Примеры запросов:**
```javascript
// Генерация капсулы
generateCapsuleWithAI({
  bestseller: { sku, name, imageBase64, colors },
  collection: { season, ageGroup, gender },
  requirements: { looksCount: 3, itemsCount: 15 }
})
```

**Токены:**
- Анализ изображения: ~1,500-2,000 tokens
- Генерация капсулы: ~4,000-8,000 tokens
- Среднее время ответа: 10-30 секунд

### 2. **Mega Prompt System**

**Компоненты промпта:**
1. **Role & Identity** - Роль AI (дизайнер KARI)
2. **Company Context** - Контекст бизнеса
3. **Price Segments** - Ценовые сегменты
4. **Safety Guidelines** - Безопасность контента
5. **Few-Shot Examples** - Примеры промптов
6. **JSON Schema** - Структура ответа

**Размер промпта:** ~2,500 токенов
