## 2. Поток Данных (Data Flow)

```
┌──────────────────────────────────────────────────────────────────┐
│                  СОЗДАНИЕ КАПСУЛЫ (AI Wizard)                    │
└──────────────────────────────────────────────────────────────────┘

1. Пользователь загружает фото бестселлера
   │
   ├─► Фото конвертируется в Base64
   │
   ▼
2. Нажимает "Сгенерировать"
   │
   ├─► Собираются данные:
   │   • Изображение (Base64)
   │   • Сезон (AW26/SS26)
   │   • Возраст (2-7, 7-14 лет)
   │   • Пол (мальчики/девочки/унисекс)
   │   • Количество образов (3-10)
   │   • Количество артикулов (10-50)
   │
   ▼
3. Формируется MEGA PROMPT
   │
   ├─► Промпт включает:
   │   • Role & Identity (дизайнер KARI)
   │   • Company Context (бизнес, приоритеты)
   │   • Price Segments (эконом/стандарт/премиум)
   │   • Safety Guidelines (детский контент)
   │   • Few-Shot Examples (примеры промптов)
   │   • JSON Schema (структура ответа)
   │
   ▼
4. Запрос отправляется через Cloudflare Worker
   │
   ├─► fetch('https://kari-claude-proxy.workers.dev/', {
   │     model: 'claude-sonnet-4-20250514',
   │     max_tokens: 8192,
   │     messages: [...]
   │   })
   │
   ▼
5. Claude API анализирует и генерирует
   │
   ├─► Ответ (JSON):
   │   {
   │     capsule: { name, season, ... },
   │     palette: { colors: [ Pantone TCX ] },
   │     looks: [ { name, items: [...] } ],
   │     items: [
   │       {
   │         sku, name, category,
   │         colors, materials,
   │         prompt: "Midjourney промпт"
   │       }
   │     ]
   │   }
   │
   ▼
6. Парсинг JSON ответа
   │
   ├─► Валидация структуры
   ├─► Проверка safety markers
   │
   ▼
7. Сохранение данных
   │
   ├─► LocalStorage (немедленно)
   │   localStorage.setItem('kari-capsules', ...)
   │
   ├─► Firestore (через 1 сек debounce)
   │   db.collection('users/{userId}/capsules').add(...)
   │
   ▼
8. Обновление UI
   │
   └─► Отображение капсулы на главной странице
```

## 3. Синхронизация Данных

```
┌──────────────────────────────────────────────────────────────────┐
│              ОБЛАЧНЫЙ РЕЖИМ (Cloud Mode)                         │
└──────────────────────────────────────────────────────────────────┘

Пользователь изменяет капсулу
   │
   ▼
┌──────────────────────┐
│   LocalStorage       │  ◄─── Сохранение (немедленно)
└──────────────────────┘
   │
   │ Debounce (1 секунда)
   ▼
┌──────────────────────┐
│  Очередь изменений   │  ◄─── Группировка операций
└──────────────────────┘
   │
   │ Проверка интернета
   ▼
┌──────────────────────┐
│  Firebase Firestore  │  ◄─── Синхронизация
└──────────────────────┘
   │
   ├─► Успех: Обновить индикатор "✅ Сохранено"
   │
   └─► Ошибка: Повторить через 5 сек


┌──────────────────────────────────────────────────────────────────┐
│              ГОСТЕВОЙ РЕЖИМ (Guest Mode)                         │
└──────────────────────────────────────────────────────────────────┘

Пользователь изменяет капсулу
   │
   ▼
┌──────────────────────┐
│   LocalStorage       │  ◄─── Только локальное хранение
└──────────────────────┘
   │
   └─► Индикатор: "💾 Локально"


┌──────────────────────────────────────────────────────────────────┐
│           ВОССТАНОВЛЕНИЕ ПРИ ВХОДЕ В ОБЛАКО                     │
└──────────────────────────────────────────────────────────────────┘

Пользователь входит в аккаунт
   │
   ├─► Загрузка из Firestore
   │   db.collection('users/{userId}/capsules').get()
   │
   ├─► Сравнение с LocalStorage
   │   • Если Firestore новее → перезаписать LocalStorage
   │   • Если LocalStorage новее → загрузить в Firestore
   │   • Если конфликт → спросить пользователя
   │
   └─► Синхронизация завершена
```

## 6. API Запросы

```
┌────────────────────────────────────────────────────────────────┐
│           ЗАПРОС К CLAUDE API (через прокси)                   │
└────────────────────────────────────────────────────────────────┘

Клиент (браузер)
   │
   │ POST https://kari-claude-proxy.workers.dev/
   │ Headers: { "Content-Type": "application/json" }
   │
   │ Body:
   │ {
   │   "model": "claude-sonnet-4-20250514",
   │   "max_tokens": 8192,
   │   "system": "Ты — дизайнер KARI GROUP...",
   │   "messages": [
   │     {
   │       "role": "user",
   │       "content": [
   │         {
   │           "type": "image",
   │           "source": {
   │             "type": "base64",
   │             "media_type": "image/jpeg",
   │             "data": "iVBORw0KGgoAAAA..."
   │           }
   │         },
   │         {
   │           "type": "text",
   │           "text": "Проанализируй бестселлер и создай капсулу"
   │         }
   │       ]
   │     }
   │   ]
   │ }
   │
   ▼
Cloudflare Worker (Прокси)
   │
   │ • Добавляет API ключ:
   │   "x-api-key": "sk-ant-api03-***"
   │
   │ • Логирование (опционально)
   │
   │ POST https://api.anthropic.com/v1/messages
   │
   ▼
Anthropic Claude API
   │
   │ • Обработка изображения
   │ • Генерация ответа
   │ • Форматирование JSON
   │
   │ Response:
   │ {
   │   "id": "msg_01...",
   │   "type": "message",
   │   "role": "assistant",
   │   "content": [
   │     {
   │       "type": "text",
   │       "text": "{\n  \"capsule\": {...},\n  \"palette\": {...},\n  ...}"
   │     }
   │   ],
   │   "model": "claude-sonnet-4-20250514",
   │   "usage": {
   │     "input_tokens": 2500,
   │     "output_tokens": 5800
   │   }
   │ }
   │

   │
   │ • Пересылает ответ клиенту
   │
   ▼
Клиент (браузер)
   │
   │ • Парсит JSON из content[0].text
   │ • Валидирует структуру
   │ • Сохраняет в LocalStorage + Firestore
```

## 7. PWA Архитектура

```
┌────────────────────────────────────────────────────────────────┐
│                   PWA LIFECYCLE                                │
└────────────────────────────────────────────────────────────────┘

Первое посещение:
   │
   ├─► Загрузка index.html
   │
   ├─► Регистрация Service Worker
   │   navigator.serviceWorker.register('/sw.js')
   │
   ├─► Service Worker устанавливается
   │   event: 'install'
   │   └─► Кэширование статики (HTML, CSS, JS, Icons)
   │
   ├─► Service Worker активируется
   │   event: 'activate'
   │   └─► Удаление старых кэшей
   │
   └─► Приложение готово к работе


Повторное посещение:
   │
   ├─► Service Worker перехватывает запросы
   │   event: 'fetch'
   │
   ├─► Проверка кэша
   │   caches.match(request)
   │
   ├─► Если в кэше → вернуть из кэша (быстро!)
   │   └─► В фоне обновить кэш из сети
   │
   └─► Если нет → загрузить из сети


Оффлайн режим:
   │
   ├─► Нет интернета
   │
   ├─► Service Worker возвращает из кэша
   │
   └─► Приложение работает полностью оффлайн
       • Просмотр капсул
       • Редактирование артикулов
       • Создание новых капсул (без AI)


Возврат онлайн:
   │
   ├─► Background Sync активируется
   │   event: 'sync'
   │
   └─► Синхронизация изменений с Firestore
```
