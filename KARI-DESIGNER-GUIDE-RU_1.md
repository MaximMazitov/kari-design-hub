## Начало работы

### Открытие приложения
1. Перейдите по ссылке: **http://localhost:8080** (локально) или задеплоенный URL
2. Появится экран входа в систему
3. Введите email и пароль для синхронизации с облаком
4. Или нажмите **"Продолжить без облака"** для локальной работы

### Вход в систему

| Режим | Описание |
|-------|----------|
| **Облако** | Данные синхронизируются между устройствами через Firebase |
| **Локально** | Данные хранятся только на вашем устройстве |

### Интерфейс

| Вкладка | Назначение |
|---------|------------|
| **Капсулы** | Создание и управление капсульными коллекциями |
| **Артикулы** | Просмотр и редактирование артикулов в капсуле |
| **Промпты** | Шаблоны промптов для генерации изображений |
| **Палитра** | Управление цветовыми палитрами Pantone |
| **Чеклисты** | Контроль качества и проверки |
| **Claude** | AI-ассистент для анализа и генерации |

## Создание капсулы

### Способ 1: Ручное создание

1. Нажмите **"+ Новая капсула"**
2. Заполните форму:
   - **Название** — например, "Summer Bloom 2025"
   - **Сезон** — SS25, AW25, SS26, AW26
   - **Возраст** — 0-24м, 2-7 лет, 4-10 лет, 7-14 лет
   - **Пол** — Мальчики, Девочки, Унисекс
   - **Сегмент** — Casual, Sport, School, Outdoor
   - **Описание** — краткое описание концепции
3. Нажмите **"Создать"**

### Способ 2: AI Capsule Wizard (Рекомендуется)

1. Нажмите **"AI Wizard"** на главном экране
2. Пройдите 4 шага:

#### Шаг 1: Бестселлер
- Загрузите фото бестселлера (вашего или конкурента)
- Укажите SKU или артикул
- AI проанализирует стиль и цвета

#### Шаг 2: Данные
- Выберите **возрастную группу**
- Выберите **пол**
- Отметьте **сегменты** (можно несколько)

#### Шаг 3: Коллекция
- Настройте **количество образов** (3-10)
- Настройте **количество артикулов** (10-50)
- Добавьте **пожелания** (опционально)

#### Шаг 4: Генерация
- Проверьте данные
- Нажмите **"Сгенерировать"**
- Дождитесь завершения (30-60 секунд)

**Результат:** Готовая капсула с:
- Цветовой палитрой Pantone TCX
- Структурой образов (looks)
- Артикулами с промптами для генерации
- Рекомендациями по материалам

## Работа с артикулами

### Просмотр артикулов
1. Откройте вкладку **"Артикулы"**
2. Выберите капсулу в выпадающем списке
3. Артикулы отображаются в виде карточек или таблицы

### Статусы артикулов

| Статус | Цвет | Значение |
|--------|------|----------|
| Бриф | Серый | Только создан |
| Промпт | Синий | Создан промпт |
| Генерация | Жёлтый | Идёт генерация изображения |
| Проверка | Оранжевый | Ожидает утверждения |
| Готово | Зелёный | Утверждён к производству |

### Редактирование артикула
1. Нажмите на карточку артикула
2. Откроется модальное окно с полями:
   - **Название** — название изделия
   - **SKU** — артикул (генерируется автоматически)
   - **Категория** — тип одежды
   - **Цвета** — из палитры капсулы
   - **Материалы** — состав ткани
   - **Промпт** — текст для генерации изображения
3. Нажмите **"Сохранить"**

### Генерация промпта для артикула
1. Откройте артикул
2. Нажмите **"Генерировать промпт"**
3. AI создаст промпт на основе данных артикула
4. Промпт автоматически включает:
   - Описание изделия
   - Цвета Pantone
   - Возраст модели
   - **Safety markers** (обязательно для детского контента)

## Работа с палитрами

### Создание палитры
1. Откройте вкладку **"Палитра"**
2. Нажмите **"+ Новая палитра"**
3. Введите название
4. Добавьте цвета:
   - **Код Pantone TCX** — например, "19-4052 TCX"
   - **Название** — например, "Classic Blue"
   - **Процент** — доля цвета в коллекции
5. Нажмите **"Сохранить"**

### Формат цветов Pantone

```
Правильно: 19-4052 TCX, 17-1463 TCX
Неправильно: #3498db, синий, Pantone Blue
```

### Привязка палитры к капсуле
1. Откройте капсулу
2. Нажмите **"Редактировать"**
3. Выберите палитру из списка
4. Сохраните изменения

## Экспорт и импорт данных

### Экспорт в Excel
1. Откройте вкладку **"Экспорт"** (или кнопка в капсуле)
2. Выберите капсулу
3. Нажмите **"Скачать XLSX"**
4. Файл содержит:
   - Список артикулов
   - Цветовую палитру
   - Промпты для генерации
   - Статусы готовности

### Резервное копирование (Backup)
1. Нажмите кнопку **"Backup"** в правом верхнем углу
2. Выберите **"Экспорт JSON"** для сохранения всех данных
3. Файл `kari-hub-backup-ДАТА.json` скачается автоматически

### Восстановление из бэкапа
1. Нажмите **"Backup"** > **"Импорт JSON"**
2. Выберите файл бэкапа
3. Данные будут восстановлены

## Синхронизация с облаком

### Индикатор статуса (внизу слева)

| Индикатор | Значение |
|-----------|----------|
| **Облако + имя** | Подключён к облаку |
| **Синхронизация...** | Идёт синхронизация |
| **Сохранено** | Данные синхронизированы |
| **Локально** | Работа без облака |
| **Ошибка** | Проблема с синхронизацией |

### Ручная синхронизация
- Нажмите `Ctrl+S` / `Cmd+S`
- Или кликните на индикатор статуса

### Выход из облака
- Нажмите на индикатор > подтвердите выход

## Важные правила

### Safety Markers для детского контента
Все промпты для генерации изображений **ОБЯЗАТЕЛЬНО** должны содержать:

```
"Professional child model"
"Fully clothed"
"Safe content"
"Commercial studio photography"
"Age [X]-year-old"
```

AI автоматически добавляет эти маркеры. **Не удаляйте их!**

### Материалы
- Смесовые ткани (полиэстер + хлопок) — рекомендуется
- Эко-кожа — допускается
- 100% натуральные материалы — только по запросу
- Натуральная кожа — не используется

### Ценовой сегмент
- Розничная цена: **890 — 19 990 руб**
- Учитывайте при выборе материалов и сложности

## Решение проблем

| Проблема | Решение |
|----------|---------|
| Страница не загружается | Нажмите Ctrl+Shift+R (очистить кэш) |
| Данные не сохраняются | Проверьте интернет и статус облака |
| AI не отвечает | Подождите 30 сек, попробуйте снова |
| Ошибка генерации | Нажмите "Попробовать снова" |
| Капсула пустая | Проверьте что выбрана нужная капсула |
| Не входит в облако | Проверьте email и пароль |

### Если ничего не помогает:
1. Обновите страницу (F5)
2. Очистите кэш (Ctrl+Shift+R)
3. Попробуйте другой браузер (Chrome рекомендуется)
4. Экспортируйте данные через Backup перед перезагрузкой
5. Сообщите администратору
